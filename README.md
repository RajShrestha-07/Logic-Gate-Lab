# Logic Gate Lab

Logic Gate Lab is a small web app that shows how logic gates work. Pick a gate, flip the input switches, and watch the output lamp and truth table update. A second section shows a full adder, the circuit a CPU uses to add numbers.

Live demo: https://YOUR-USERNAME.github.io/Logic-Gate-Lab/

Built with: HTML, CSS and JavaScript.

What this project shows: Every digital chip is built from simple gates like AND, OR, NOT and XOR. Each gate takes 1s and 0s and gives back a 1 or 0, and a truth table lists every possible result. Combining XOR and AND gates makes a full adder, which adds two bits plus a carry. Chaining eight of them adds two bytes.

What I'm learning from it: I'm studying how the gate functions in the code work (for example, AND is `a & b` and NAND is `(a & b) ^ 1`) and how the adder's sum and carry formulas produce binary addition.
